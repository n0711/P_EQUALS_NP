\begin{abstract}
A reproducible study combines exact graph-separator conditioning,
incidence-component decomposition and a conservative polynomial-time
recognizer for complete XOR constraint blocks in Boolean CNF formulas.
We introduce a seeded benchmark infrastructure for connected cubic
Tseitin parity formulas, pigeonhole constraints and graph coloring.
These are implementations of established graph-search and algebraic
techniques. No proof that $\mathsf{P}=\mathsf{NP}$ is established.
\end{abstract}

\section{Exact graph conditioning}
Let $F$ be a CNF formula and $S$ a set of its variables.
An assignment $\alpha$ to $S$ restricts $F$ by deleting true
clauses and false literals. For a residual formula, its primal
graph joins variables co-occurring in a clause.

\begin{theorem}
$F$ is satisfiable if and only if there exists an assignment
$\alpha\in\{0,1\}^{S}$ such that every variable-disjoint connected
component of $F|_\alpha$ is satisfiable.
\end{theorem}
\begin{proof}
Any satisfying assignment of $F$ restricts to a choice of $\alpha$,
and its remaining values satisfy each component. Conversely,
satisfying assignments of disjoint components combine with
$\alpha$ into a satisfying assignment of $F$. Therefore exhaustive
separator conditioning preserves the SAT decision.
\end{proof}

\begin{proposition}
For explicit input size $N$, suppose a separator of size at most
$s$ is found in polynomial time and all its assignments leave
components of size at most $b$. Complete component search after
conditioning has time upper bound
\[
T(N)=\operatorname{poly}(N)2^{O(s+b)}.
\]
In particular, $s+b=O(\log N)$ implies polynomial time for
this restricted class.
\end{proposition}
\begin{proof}
There are $2^s$ assignments to the separator, each yielding at
most polynomially many explicit components, each of which can
be decided in $2^{O(b)}\operatorname{poly}(N)$ bit operations.
Multiplication gives the claim. The condition is not proved
for arbitrary CNF.
\end{proof}

The program \texttt{graph\_separator\_sat.py} searches for single
or paired primal-graph vertex separators and falls back to
complete branching. General worst-case running time is exponential.

\section{Affine-CNF recognition over the field with two elements}
A clause with exactly one literal on each variable in a fixed
support $X$ is falsified by exactly one truth assignment on $X$.
For $1\le |X|\le3$, when the clause set contains precisely all
$2^{|X|-1}$ clauses that forbid one parity class, it enforces
the complementary XOR parity equation. A conjunction of such
complete blocks is therefore a linear system over $\mathbb F_2$.

\begin{theorem}
Recognized complete parity CNF blocks are decided exactly in
polynomial time by Gaussian elimination over $\mathbb F_2$.
A complete exact SAT fallback on unrecognized inputs preserves
correctness, but not a general polynomial-time guarantee.
\end{theorem}
\begin{proof}
The forbidden assignments are exactly one of the two parity
classes, so each recognized block is equivalent to its XOR
equation. Gaussian elimination correctly decides the conjunction
and recovers a solution where one exists. Recognition failure
triggers an independent complete decision procedure rather
than a spurious UNSAT answer.
\end{proof}

\section{Falsifiable graph experiments}
The benchmark generator builds a connected cubic graph, one
Boolean variable per edge, and a parity constraint at each vertex.
Each constraint yields four 3-CNF clauses. XORing all vertex
equations cancels each edge variable twice. An odd total parity
charge therefore requires $0=1$ and is unsatisfiable; even total
charge on a connected graph admits a solution.

Additional cases include 3-CNF pigeonhole contradictions and
clique three-coloring. Min-fill elimination produces an upper
bound on primal treewidth, while degeneracy is a lower bound.
Neither is a general SAT running-time lower bound.


\section{M6: Same-primal-graph satisfiable and unsatisfiable CNFs}

A graph-only SAT criterion is insufficient even for a complete primal graph.
For $n\ge3$, define
\[
{\cal T}_n=\{T\subseteq[n]:|T|=3\}.
\]
Consider the following three explicit clause families:
\begin{align}
A_n &= \bigwedge_{T\in{\cal T}_n}
          \left(\bigvee_{i\in T}x_i\right),\\
B_n &= \bigwedge_{T\in{\cal T}_n}
       \bigwedge_{b\in\{0,1\}^{T}}
        \left(\bigvee_{i\in T}
          \begin{cases}x_i&b_i=0,\\\neg x_i&b_i=1,\end{cases}\right),\\
C_n &= \bigwedge_{T\in{\cal T}_n}
       \left(\bigvee_{i\in T}x_i\right)
       \wedge\left(\bigvee_{i\in T}\neg x_i\right).
\end{align}
In the expression for $B_n$, each sign choice excludes precisely
one assignment $b$ to its triple; the displayed cases specify
the corresponding literal, not a conditional algorithm.

\begin{theorem}[Identical graph, distinct SAT outcomes]
For every $n\ge3$, formulas $A_n$, $B_n$ and $C_n$ have
identical primal graph $K_n$ and treewidth $n-1$.
Formula $A_n$ is SAT; $B_n$ is UNSAT; and
$C_n$ is SAT if and only if $n\le4$.
\end{theorem}
\begin{proof}
Every pair of distinct variables occurs together in at least
one triple because $n\ge3$, hence every primal graph equals
$K_n$. Setting every variable True satisfies $A_n$.
Any complete assignment to the first triple falsifies one of
its eight possible signed clauses, so $B_n$ is UNSAT.
For $C_n$, every positive triple must contain a True literal,
equivalently there are at most two False variables; likewise,
every negative triple must contain a False literal, so at most
two variables are True. Both can hold if and only if $n\le4$
under the assumption $n\ge3$. For $n=3,4$ explicit
assignments with one or two True values suffice.
\end{proof}

\begin{proposition}[Exact bounded-width support detection]
Let $S$ be a fixed support of $k$ distinct variables.
If a CNF includes all $2^k$ non-tautological signed clauses,
each mentioning exactly the variables $S$, the CNF is UNSAT.
For fixed $k\le3$ this condition can be detected in polynomial
time in the explicit CNF size.
\end{proposition}
\begin{proof}
Each signed clause forbids exactly one truth assignment to $S$.
With all $2^k$ sign choices, every assignment to $S$ falsifies
at least one clause. Normalization and grouping by support
take polynomial time in the explicit number of literals.
\end{proof}

The new implementation \texttt{polarity\_sat.py} applies
normalization, complete-support contradiction detection,
standard unit propagation and pure-literal elimination before
the already verified affine-and-separator fallback. Pure-literal
elimination is equisatisfiable and records its assignments
for final witness reconstruction. This is classical SAT
preprocessing, not a new universal polynomial-time method.

The first formula family is immediately handled by pure-literal
elimination, and the second by a complete-support contradiction.
For the third family, the same preprocessing finds no unit
or pure literals and no complete triple-support block;
the exact fallback is still needed. The latter observation
is a limitation, not evidence of exponential lower bounds.

The experiment script \texttt{run\_polarity\_benchmark.py}
compares the exact DPLL baseline, the affine-graph hybrid and
the polarity-aware hybrid on these graph-identical inputs.
Any \texttt{timeout} or \texttt{limit\_calls} result is
\emph{undecided}, not UNSAT. Run and artifact IDs for each
validated result are appended in the milestone ledger.

\section{Evidence, limitations and manuscript updates}
The cumulative research log is
\texttt{RESEARCH\_MILESTONES.md}. Milestones M3 and M4 contain
previously tested exact decomposition and graph-separator methods.
Milestone M5 adds an affine recognizer and graph-theoretic stress
families. On 7 November 2026, GitHub Actions run 42401754276
completed 37 Python unittest methods successfully, including eleven
M5 structural hybrid tests. The bounded quick benchmark step
also completed and archived its raw JSON under artifact ID
13586040475. These observations concern finite validation only,
and do not establish runtime improvement or a general bound.

Each solver run has either a completed SAT/UNSAT result,
an explicit call-limit status, or a timeout. The latter outcomes
are not UNSAT answers. Results should report seeds, input size,
runtime, memory measurement method and independently checked
models. Python tracked allocations are not total resident memory.
Experiments do not demonstrate a universal polynomial-time bound.

To establish $\mathsf{P}=\mathsf{NP}$ via SAT, it remains necessary
to exhibit a deterministic SAT algorithm whose total bit-operation
cost is bounded by $CN^c$ for fixed constants $C,c$ on every
encoded CNF. None of the present milestones supplies that theorem.
