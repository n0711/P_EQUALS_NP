\begin{abstract}
A reproducible study combines exact graph-separator conditioning,
incidence-component decomposition and a conservative polynomial-time
recognizer for complete XOR constraint blocks in Boolean CNF formulas.
We introduce a seeded benchmark infrastructure for connected cubic
Tseitin parity formulas, pigeonhole constraints and graph coloring.
These are implementations of established graph-search and algebraic
techniques. No proof that $\mathsf{P}=\mathsf{NP}$ is established.
\end{abstract}

\section{Background and research provenance}
The author previously released a foundations manuscript on
ResearchGate \cite{nadiotis}. The present working report is separate
from that work and extends the exact SAT experiments recorded in
the repository. Structural AND/OR search \cite{dechter} and the
tractability of affine constraint classes \cite{schaefer} provide
established mathematical context.

\section{Exact graph conditioning}
Let $F$ be a CNF formula and $S$ a set of its variables.
An assignment $\alpha$ to $S$ restricts $F$ by deleting true
clauses and false literals. For a residual formula, its primal
graph joins variables co-occurring in a clause.

\begin{theorem}
$F$ is satisfiable if and only if there exists an assignment
$\alpha\in\{0,1\}^{S}$ such that every variable-disjoint connected
component of $F|_\alpha$ is satisfiable.
\end{theorem}
\begin{proof}
Any satisfying assignment of $F$ restricts to a choice of $\alpha$,
and its remaining values satisfy each component. Conversely,
satisfying assignments of disjoint components combine with
$\alpha$ into a satisfying assignment of $F$. Therefore exhaustive
separator conditioning preserves the SAT decision.
\end{proof}

\begin{proposition}
For explicit input size $N$, suppose a separator of size at most
$s$ is found in polynomial time and all its assignments leave
components of size at most $b$. Complete component search after
conditioning has time upper bound
\[
T(N)=\operatorname{poly}(N)2^{O(s+b)}.
\]
In particular, $s+b=O(\log N)$ implies polynomial time for
this restricted class.
\end{proposition}
\begin{proof}
There are $2^s$ assignments to the separator, each yielding at
most polynomially many explicit components, each of which can
be decided in $2^{O(b)}\operatorname{poly}(N)$ bit operations.
Multiplication gives the claim. The condition is not proved
for arbitrary CNF.
\end{proof}

The program \texttt{graph\_separator\_sat.py} searches for single
or paired primal-graph vertex separators and falls back to
complete branching. General worst-case running time is exponential.

\section{Affine-CNF recognition over the field with two elements}
A clause with exactly one literal on each variable in a fixed
support $X$ is falsified by exactly one truth assignment on $X$.
For $1\le |X|\le3$, when the clause set contains precisely all
$2^{|X|-1}$ clauses that forbid one parity class, it enforces
the complementary XOR parity equation. A conjunction of such
complete blocks is therefore a linear system over $\mathbb F_2$.

\begin{theorem}
Recognized complete parity CNF blocks are decided exactly in
polynomial time by Gaussian elimination over $\mathbb F_2$.
A complete exact SAT fallback on unrecognized inputs preserves
correctness, but not a general polynomial-time guarantee.
\end{theorem}
\begin{proof}
The forbidden assignments are exactly one of the two parity
classes, so each recognized block is equivalent to its XOR
equation. Gaussian elimination correctly decides the conjunction
and recovers a solution where one exists. Recognition failure
triggers an independent complete decision procedure rather
than a spurious UNSAT answer.
\end{proof}

\section{Falsifiable graph experiments}
The benchmark generator builds a connected cubic graph, one
Boolean variable per edge, and a parity constraint at each vertex.
Each constraint yields four 3-CNF clauses. XORing all vertex
equations cancels each edge variable twice. An odd total parity
charge therefore requires $0=1$ and is unsatisfiable; even total
charge on a connected graph admits a solution.

Additional cases include 3-CNF pigeonhole contradictions and
clique three-coloring. Min-fill elimination produces an upper
bound on primal treewidth, while degeneracy is a lower bound.
Neither is a general SAT running-time lower bound.


\section{M6: Same-primal-graph satisfiable and unsatisfiable CNFs}

A graph-only SAT criterion is insufficient even for a complete primal graph.
For $n\ge3$, define
\[
{\cal T}_n=\{T\subseteq[n]:|T|=3\}.
\]
Consider the following three explicit clause families:
Define $\ell_i(0)=x_i$ and $\ell_i(1)=\neg x_i$.
Then
\begin{align}
A_n &= \bigwedge_{T\in{\cal T}_n}
          \left(\bigvee_{i\in T}x_i\right),\\
B_n &= \bigwedge_{T\in{\cal T}_n}
       \bigwedge_{b\in\{0,1\}^{T}}
        \left(\bigvee_{i\in T}\ell_i(b_i)\right),\\
C_n &= \bigwedge_{T\in{\cal T}_n}
       \left[
       \left(\bigvee_{i\in T}x_i\right)
       \wedge\left(\bigvee_{i\in T}\neg x_i\right)
       \right].
\end{align}
In $B_n$ every sign choice excludes precisely one assignment
to its support triple.

\begin{theorem}[Identical graph, distinct SAT outcomes]
For every $n\ge3$, formulas $A_n$, $B_n$ and $C_n$ have
identical primal graph $K_n$ and treewidth $n-1$.
Formula $A_n$ is SAT; $B_n$ is UNSAT; and
$C_n$ is SAT if and only if $n\le4$.
\end{theorem}
\begin{proof}
Every pair of distinct variables occurs together in at least
one triple because $n\ge3$, hence every primal graph equals
$K_n$. Setting every variable True satisfies $A_n$.
Any complete assignment to the first triple falsifies one of
its eight possible signed clauses, so $B_n$ is UNSAT.
For $C_n$, every positive triple must contain a True literal,
equivalently there are at most two False variables; likewise,
every negative triple must contain a False literal, so at most
two variables are True. Both can hold if and only if $n\le4$
under the assumption $n\ge3$. For $n=3,4$ explicit
assignments with one or two True values suffice.
\end{proof}

\begin{proposition}[Exact bounded-width support detection]
Let $S$ be a fixed support of $k$ distinct variables.
If a CNF includes all $2^k$ non-tautological signed clauses,
each mentioning exactly the variables $S$, the CNF is UNSAT.
For fixed $k\le3$ this condition can be detected in polynomial
time in the explicit CNF size.
\end{proposition}
\begin{proof}
Each signed clause forbids exactly one truth assignment to $S$.
With all $2^k$ sign choices, every assignment to $S$ falsifies
at least one clause. Normalization and grouping by support
take polynomial time in the explicit number of literals.
\end{proof}

The new implementation \texttt{polarity\_sat.py} applies
normalization, complete-support contradiction detection,
standard unit propagation and pure-literal elimination before
the already verified affine-and-separator fallback. Pure-literal
elimination is equisatisfiable and records its assignments
for final witness reconstruction. This is classical SAT
preprocessing, not a new universal polynomial-time method.

The first formula family is immediately handled by pure-literal
elimination, and the second by a complete-support contradiction.
For the third family, the same preprocessing finds no unit
or pure literals and no complete triple-support block;
the exact fallback is still needed. The latter observation
is a limitation, not evidence of exponential lower bounds.

The experiment script \texttt{run\_polarity\_benchmark.py}
compares the exact DPLL baseline, the affine-graph hybrid and
the polarity-aware hybrid on these graph-identical inputs.
Any \texttt{timeout} or \texttt{limit\_calls} result is
\emph{undecided}, not UNSAT. Run and artifact IDs for each
validated result are appended in the milestone ledger.


\section{M7: Generalized Sudoku and RioTuner-inspired Fourier integrals}

\subsection{Nondeterministic graph-coloring formulation}
Let $b\ge1$ denote the box width and $q=b^2$. A generalized Sudoku
board has $q$ rows, $q$ columns, $q^2$ cells, and labels $1,\ldots,q$.
Create a vertex per cell; connect two vertices if and only if their
cells share a row, column, or $b\times b$ box. An assignment
$c:V\rightarrow[q]$ respects a Sudoku puzzle precisely when it
is a proper graph coloring and preserves every prescribed given digit.

\begin{theorem}[Polynomial witness verification]
Generalized Sudoku belongs to $\mathsf{NP}$.
\end{theorem}
\begin{proof}
A certificate contains one color per cell, a total of $q^2$
integers each represented in $O(\log q)$ bits. A deterministic
verifier confirms the digits lie in $[q]$, checks prescribed
givens, and compares assigned colors across every graph edge.
Each vertex has $O(q)$ neighbors, so $|E|=O(q^3)$, and
verification is polynomial in the explicit board size.
A nondeterministic machine guesses this certificate.
The argument does not show a deterministic polynomial-time
method for discovering a certificate.
\end{proof}

NP-completeness for generalized Number Place
was established by Yato and Seta~\cite{yato2003}.
This separate published hardness result is not
derived from membership in NP alone.

The reference implementation
\texttt{sudoku\_graph\_np.py} constructs the graph, checks
certificates, and solves examples via deterministic
constraint propagation and backtracking. It is exact when
completed, but its worst case may be exponential.
An explicit node budget yields an \emph{undecided} status
rather than an unsatisfiability certificate.

\subsection{A Fourier integral as a color-conflict indicator}
The author's separate RioTuner engine (repository
\texttt{n0711/riotuner}, \texttt{engine/src/partials.rs})
uses weighted complex phase demodulation to estimate
audio frequency. Here we transfer only its Fourier
projection principle, not the audio code or its
pitch-estimation guarantees.

\begin{theorem}[Fourier--Kronecker projection]
For colors $a,b\in\{1,\ldots,q\}$, define
\begin{equation}
\delta_q(a,b)=\frac{1}{2\pi}\int_0^{2\pi}
 e^{i(a-b)t}\,dt =
 \frac1q\sum_{k=0}^{q-1}
 e^{2\pi i k(a-b)/q}.
\end{equation}
Then $\delta_q(a,b)=1$ if $a=b$ and is zero otherwise.
For any complete coloring $c$, the energy
\begin{equation}
E(c)=\sum_{\{u,v\}\in E}\delta_q(c(u),c(v))
\end{equation}
equals the integer number of same-color graph edges.
\end{theorem}
\begin{proof}
If $a=b$, every integrand and discrete summand equals one.
Otherwise $d=a-b$ is a nonzero integer with $|d|<q$.
Integrating the nonconstant integer-frequency exponential
over the circle gives zero. In the discrete sum,
$\omega=e^{2\pi i d/q}$ is a nontrivial $q$th root
of unity, hence
$\sum_{k=0}^{q-1}\omega^k=(1-\omega^q)/(1-\omega)=0$.
Summing edge indicators gives the collision count.
\end{proof}

For a \emph{complete} coloring, zero energy together
with preserved givens is exactly a Sudoku solution.
For a partial assignment, zero conflicts among assigned
cells cannot decide whether a full solution exists.
Evaluating the displayed discrete phase sum directly
requires $O(q|E|)$ numerical operations, whereas direct
exact integer comparisons require $O(|E|)$. The
integral notation therefore does \emph{not} improve
the complexity of certificate checking.

\paragraph{Audio window transfer obstruction.}
RioTuner uses a nonuniform four-term Blackman--Harris
analysis window. Replacing the uniform coefficients
in the finite Fourier sum by these weights generally
destroys exact character orthogonality. The resulting
nonzero leakage can appear even for valid Sudoku
colorings. Consequently, weighted phase diagnostics
and floating-point cancellation are not valid SAT
or Sudoku decision certificates.

\subsection{Polynomial encoding and counting obstruction}
The module \texttt{sudoku\_graph\_to\_sat.py}
encodes one Boolean variable for each cell-color pair,
for a total of $q^3$ variables. Clauses enforce
exactly one color per cell, unequal colors along graph
edges, and the original givens. The encoding has
$O(q^4)$ explicit size and preserves solutions:
Sudoku reduces to CNF-SAT in polynomial time.

Let $D$ be the given-cell set and $g_v$ its required
color. The number of valid completions is
\begin{equation}
Z=\sum_{c\in[q]^V}
\left[\prod_{\{u,v\}\in E}
 (1-\delta_q(c(u),c(v)))\right]
\left[\prod_{v\in D}\delta_q(c(v),g_v)\right].
\end{equation}
There are $q^{q^2}$ candidate complete colorings.
Replacing the indicators by Fourier integrals does
not itself provide a polynomial procedure to evaluate
this partition function.

\section{M8: Exact Sudoku counting by graph row-transfer states}

The researcher reports that the previous M7 Sudoku and
RioTuner-inspired Fourier-integral report was posted
on ResearchGate. The publication identifier was not
independently verified for the present milestone.
We now examine whether exact graph constraint
contraction can evaluate the Sudoku partition function
more efficiently than direct enumeration of all
$q^{q^2}$ complete color assignments.

\subsection{Integer transfer recurrence}
Retain the M7 notation $q=b^2$ for a generalized
Sudoku board with $q$ rows and columns and
$b\times b$ sub-boxes. Every valid full row is a
permutation $p=(p_0,\ldots,p_{q-1})$ of $[q]$.
After processing $r$ rows, keep a state
\begin{equation}
\sigma_r=(C_0,\ldots,C_{q-1}, B_0,\ldots,B_{b-1}),
\end{equation}
where $C_j$ is the $q$-bit set of digits already
used in column $j$ and $B_k$ is the set used in the
currently processed band of $b$ rows in box-column
$k$. Reset the $B_k$ at the start of each new
box-row band. A row permutation is admissible
precisely when it respects its givens and no inserted
digit occurs in its corresponding column or active
box mask.

Write $\Pi_r(\sigma)$ for the set of admissible
row permutations and $U_r(\sigma,p)$ for the
deterministic successor state. Define the suffix
count recursively by
\begin{equation}
D_r(\sigma)=
\begin{cases}
1,&r=q,\\
\displaystyle\sum_{p\in\Pi_r(\sigma)}
D_{r+1}\bigl(U_r(\sigma,p)\bigr),&r<q.
\end{cases}
\label{eq:transfer}
\end{equation}
The algorithm stores a memoized integer result for
each encountered pair $(r,\sigma)$ and records
one positive-count transition to reconstruct
a witness.

\begin{theorem}[Exact Sudoku transfer counting]
For a generalized Sudoku instance with arbitrary
givens, $D_0(\mathbf{0})$ equals its number of
completed solutions. In particular, the initial
count is positive if and only if the puzzle is
satisfiable.
\end{theorem}
\begin{proof}
Every valid solution has exactly one ordered
sequence of row permutations. The corresponding
transfer path is admissible because its columns
and boxes contain no repeated digit and all givens
are respected. Conversely, each completed
admissible path consists of row permutations
and never repeats a digit within a column or
box. Since each completed unit has exactly $q$
cells with $q$ allowed digits, all digits occur
exactly once. Thus every accepted path represents
one valid solution, and no two accepted paths
represent the same solution. Recurrence
\eqref{eq:transfer} counts the accepted paths
exactly once by induction from its base case.
\end{proof}

This is an exact regrouping of terms in the M7
Fourier partition function, using only integer
set operations and arbitrary-precision sums.
The Fourier integral representation is a
mathematical equivalence, not a source of
additional computational power.

\subsection{A provable but restricted symmetry quotient}
For a clue-free board, the symmetric group
$S_q$ acts on completed grids by globally
relabeling all digit colors.

\begin{theorem}[Canonical first row on clue-free boards]
If a generalized Sudoku has no givens, its
exact number $Z$ of completions satisfies
\begin{equation}
Z=q!\,Z_{\mathrm{canonical}},
\end{equation}
where $Z_{\mathrm{canonical}}$ counts completions
whose first row is $(1,2,\ldots,q)$.
\end{theorem}
\begin{proof}
Every completed first row is a permutation
of $[q]$. There is exactly one global
digit relabeling that sends its first row
to the canonical ordering. Any color
permutation fixing a completed first row
must fix every digit, so this group action
is free. Thus each orbit contains precisely
$q!$ different colorings and exactly one
canonical-first-row representative.
Multiplication by $q!$ recovers the
unrestricted count.
\end{proof}

This normalization is \emph{not} applied to
puzzles with givens: changing color labels
may violate an original clue. The symmetry
argument is elementary and does not prove a
general polynomial-time Sudoku algorithm.

\subsection{Exponential state-space bound}
A transfer frontier contains $q$ column
masks and $b$ active box masks, each of $q$
bits. Hence it uses at most $q^2+bq$
bits, and the number of possible states
over all row positions is bounded by
$q\,2^{q^2+bq}$. Each state may inspect
as many as $q!$ row permutations,
with polynomial-time mask operations
and arbitrary-precision integer addition.
A loose upper bound on total bit time is
\begin{equation}
T(q)\le \operatorname{poly}(q)\,
q!\,2^{q^2+bq}.
\label{eq:transfer-bound}
\end{equation}
This bound is \emph{exponential} as the
generalized board dimension increases.
It is an upper bound for this exact
implementation, not a proven lower bound
for every Sudoku algorithm and not a
proof of $\mathsf{P}=\mathsf{NP}$.

\section{Evidence, limitations and manuscript updates}
The cumulative research log is
\texttt{RESEARCH\_MILESTONES.md}. Milestones M3 and M4 contain
previously tested exact decomposition and graph-separator methods.
Milestone M5 adds an affine recognizer and graph-theoretic stress
families. On 7 November 2026, GitHub Actions run 42401754276
completed 37 Python unittest methods successfully, including eleven
M5 structural hybrid tests. The bounded quick benchmark step
also completed and archived its raw JSON under artifact ID
13586040475. These observations concern finite validation only,
and do not establish runtime improvement or a general bound.

M6 validation was executed on 7 November 2026 in GitHub Actions
run 42403877621. All 48 Python unittest methods passed, including
11 new M6 tests with 810 seeded small-formula exhaustive-oracle
comparisons and 210 signed variable-renaming comparisons. The
bounded same-primal-graph benchmark was archived as artifact ID
13586087780, and the other SAT and graph-search checks passed.
Completion of the benchmark workflow does not imply that
time-limited individual solver calls always completed, nor
that one solver is asymptotically faster than another.

Each solver run has either a completed SAT/UNSAT result,
an explicit call-limit status, or a timeout. The latter outcomes
are not UNSAT answers. Results should report seeds, input size,
runtime, memory measurement method and independently checked
models. Python tracked allocations are not total resident memory.
Experiments do not demonstrate a universal polynomial-time bound.

To establish $\mathsf{P}=\mathsf{NP}$ via SAT, it remains necessary
to exhibit a deterministic SAT algorithm whose total bit-operation
cost is bounded by $CN^c$ for fixed constants $C,c$ on every
encoded CNF. None of the present milestones supplies that theorem.
