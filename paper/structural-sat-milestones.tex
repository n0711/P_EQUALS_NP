\begin{abstract}
A reproducible study combines exact graph-separator conditioning,
incidence-component decomposition and a conservative polynomial-time
recognizer for complete XOR constraint blocks in Boolean CNF formulas.
We introduce a seeded benchmark infrastructure for connected cubic
Tseitin parity formulas, pigeonhole constraints and graph coloring.
These are implementations of established graph-search and algebraic
techniques. No proof that $\mathsf{P}=\mathsf{NP}$ is established.
\end{abstract}

\section{Exact graph conditioning}
Let $F$ be a CNF formula and $S$ a set of its variables.
An assignment $\alpha$ to $S$ restricts $F$ by deleting true
clauses and false literals. For a residual formula, its primal
graph joins variables co-occurring in a clause.

\begin{theorem}
$F$ is satisfiable if and only if there exists an assignment
$\alpha\in\{0,1\}^{S}$ such that every variable-disjoint connected
component of $F|_\alpha$ is satisfiable.
\end{theorem}
\begin{proof}
Any satisfying assignment of $F$ restricts to a choice of $\alpha$,
and its remaining values satisfy each component. Conversely,
satisfying assignments of disjoint components combine with
$\alpha$ into a satisfying assignment of $F$. Therefore exhaustive
separator conditioning preserves the SAT decision.
\end{proof}

\begin{proposition}
For explicit input size $N$, suppose a separator of size at most
$s$ is found in polynomial time and all its assignments leave
components of size at most $b$. Complete component search after
conditioning has time upper bound
\[
T(N)=\operatorname{poly}(N)2^{O(s+b)}.
\]
In particular, $s+b=O(\log N)$ implies polynomial time for
this restricted class.
\end{proposition}
\begin{proof}
There are $2^s$ assignments to the separator, each yielding at
most polynomially many explicit components, each of which can
be decided in $2^{O(b)}\operatorname{poly}(N)$ bit operations.
Multiplication gives the claim. The condition is not proved
for arbitrary CNF.
\end{proof}

The program \texttt{graph\_separator\_sat.py} searches for single
or paired primal-graph vertex separators and falls back to
complete branching. General worst-case running time is exponential.

\section{Affine-CNF recognition over the field with two elements}
A clause with exactly one literal on each variable in a fixed
support $X$ is falsified by exactly one truth assignment on $X$.
For $1\le |X|\le3$, when the clause set contains precisely all
$2^{|X|-1}$ clauses that forbid one parity class, it enforces
the complementary XOR parity equation. A conjunction of such
complete blocks is therefore a linear system over $\mathbb F_2$.

\begin{theorem}
Recognized complete parity CNF blocks are decided exactly in
polynomial time by Gaussian elimination over $\mathbb F_2$.
A complete exact SAT fallback on unrecognized inputs preserves
correctness, but not a general polynomial-time guarantee.
\end{theorem}
\begin{proof}
The forbidden assignments are exactly one of the two parity
classes, so each recognized block is equivalent to its XOR
equation. Gaussian elimination correctly decides the conjunction
and recovers a solution where one exists. Recognition failure
triggers an independent complete decision procedure rather
than a spurious UNSAT answer.
\end{proof}

\section{Falsifiable graph experiments}
The benchmark generator builds a connected cubic graph, one
Boolean variable per edge, and a parity constraint at each vertex.
Each constraint yields four 3-CNF clauses. XORing all vertex
equations cancels each edge variable twice. An odd total parity
charge therefore requires $0=1$ and is unsatisfiable; even total
charge on a connected graph admits a solution.

Additional cases include 3-CNF pigeonhole contradictions and
clique three-coloring. Min-fill elimination produces an upper
bound on primal treewidth, while degeneracy is a lower bound.
Neither is a general SAT running-time lower bound.


\section{M6: Same-primal-graph satisfiable and unsatisfiable CNFs}

A graph-only SAT criterion is insufficient even for a complete primal graph.
For $n\ge3$, define
\[
{\cal T}_n=\{T\subseteq[n]:|T|=3\}.
\]
Consider the following three explicit clause families:
Define $\ell_i(0)=x_i$ and $\ell_i(1)=\neg x_i$.
Then
\begin{align}
A_n &= \bigwedge_{T\in{\cal T}_n}
          \left(\bigvee_{i\in T}x_i\right),\\
B_n &= \bigwedge_{T\in{\cal T}_n}
       \bigwedge_{b\in\{0,1\}^{T}}
        \left(\bigvee_{i\in T}\ell_i(b_i)\right),\\
C_n &= \bigwedge_{T\in{\cal T}_n}
       \left[
       \left(\bigvee_{i\in T}x_i\right)
       \wedge\left(\bigvee_{i\in T}\neg x_i\right)
       \right].
\end{align}
In $B_n$ every sign choice excludes precisely one assignment
to its support triple.

\begin{theorem}[Identical graph, distinct SAT outcomes]
For every $n\ge3$, formulas $A_n$, $B_n$ and $C_n$ have
identical primal graph $K_n$ and treewidth $n-1$.
Formula $A_n$ is SAT; $B_n$ is UNSAT; and
$C_n$ is SAT if and only if $n\le4$.
\end{theorem}
\begin{proof}
Every pair of distinct variables occurs together in at least
one triple because $n\ge3$, hence every primal graph equals
$K_n$. Setting every variable True satisfies $A_n$.
Any complete assignment to the first triple falsifies one of
its eight possible signed clauses, so $B_n$ is UNSAT.
For $C_n$, every positive triple must contain a True literal,
equivalently there are at most two False variables; likewise,
every negative triple must contain a False literal, so at most
two variables are True. Both can hold if and only if $n\le4$
under the assumption $n\ge3$. For $n=3,4$ explicit
assignments with one or two True values suffice.
\end{proof}

\begin{proposition}[Exact bounded-width support detection]
Let $S$ be a fixed support of $k$ distinct variables.
If a CNF includes all $2^k$ non-tautological signed clauses,
each mentioning exactly the variables $S$, the CNF is UNSAT.
For fixed $k\le3$ this condition can be detected in polynomial
time in the explicit CNF size.
\end{proposition}
\begin{proof}
Each signed clause forbids exactly one truth assignment to $S$.
With all $2^k$ sign choices, every assignment to $S$ falsifies
at least one clause. Normalization and grouping by support
take polynomial time in the explicit number of literals.
\end{proof}

The new implementation \texttt{polarity\_sat.py} applies
normalization, complete-support contradiction detection,
standard unit propagation and pure-literal elimination before
the already verified affine-and-separator fallback. Pure-literal
elimination is equisatisfiable and records its assignments
for final witness reconstruction. This is classical SAT
preprocessing, not a new universal polynomial-time method.

The first formula family is immediately handled by pure-literal
elimination, and the second by a complete-support contradiction.
For the third family, the same preprocessing finds no unit
or pure literals and no complete triple-support block;
the exact fallback is still needed. The latter observation
is a limitation, not evidence of exponential lower bounds.

The experiment script \texttt{run\_polarity\_benchmark.py}
compares the exact DPLL baseline, the affine-graph hybrid and
the polarity-aware hybrid on these graph-identical inputs.
Any \texttt{timeout} or \texttt{limit\_calls} result is
\emph{undecided}, not UNSAT. Run and artifact IDs for each
validated result are appended in the milestone ledger.

runtime, memory measurement method and independently checked

To establish $\mathsf{P}=\mathsf{NP}$ via SAT, it remains necessary
to exhibit a deterministic SAT algorithm whose total bit-operation
cost is bounded by $CN^c$ for fixed constants $C,c$ on every
encoded CNF. None of the present milestones supplies that theorem.

\section{M7: A lower bound for the implemented fallback}
\begin{theorem}
For every $k\ge1$ there is an unsatisfiable 3-CNF on $9k$ variables
for which the M7 uncapped structural hybrid makes at least $2^{k+1}-1$
recursive calls under its current pivot and cache rules.
\end{theorem}
\begin{proof}
Use pivots $x_1,\ldots,x_k$ and a cycle of $8k$ auxiliary variables,
partitioned in cyclic order into private blocks of eight, one per pivot.
For each triple below, add its all-positive and all-negative clauses,
discarding duplicates.
Use every triple of consecutive cycle vertices (with wraparound), every
triple among the first five cycle vertices, and every triple consisting
of a pivot and an unordered pair from its block.

Among the first five vertices at least three have the same Boolean value.
One of their two clauses is false. Thus every pivot assignment is
unsatisfiable. Initially each support has two sign patterns, while the
affine recognizer requires four for width three. Both polarities occur
everywhere, with no units or complete sign block. The hybrid enters
separator search.

Consider any prefix assigning only the first $d<k$ pivots. Each assigned
pivot leaves one binary clause on each private pair, positive for a false
pivot and negative for a true one. All cycle triples survive. No unit or
empty clause appears. The primal graph contains the square of the cycle
on its auxiliary vertices. Deleting two adjacent cycle vertices leaves
a path around the other side. Isolated deleted vertices can each be
skipped by a distance-two edge. Thus deleting at most two vertices leaves
the surviving cycle vertices connected. Every surviving unassigned pivot
retains at least six neighbors on that cycle. Neither component splitting
nor a one- or two-vertex separator applies.

An unassigned pivot occurs $2\binom{8}{2}=56$ times. Each auxiliary
variable occurs at most $2(8-1)+2\cdot3+2\binom{4}{2}=32$ times,
counting private pairs, cycle triples and the five-vertex core.
Restriction can only decrease these counts. The fallback selects a
maximum-frequency variable, breaking ties by smallest ID. Number the
pivots $1,\ldots,k$, so it selects $x_{d+1}$.

At fixed depth, the binary signs on each assigned block recover its
pivot choice from the canonical clause tuple. Different prefix depths
have different remaining pivot sets. After depth $k$, a proper recursive
child also loses at least one auxiliary variable, while every depth-$k$
state retains the whole cycle. The exact-key cache therefore cannot
shortcut the prefix tree. Both branches must fail, so all $2^d$ prefixes
are called at every depth $0\le d\le k$. Summing proves the bound.
\end{proof}
The family has $O(k)$ clauses of constant width and variable IDs at
most $9k$, giving encoded length $N=O(k\log(k+1))$ with binary IDs.
The call count exceeds every fixed polynomial in $N$. This rules out
a polynomial worst-case guarantee for this implementation. A solver
that recognizes the five-vertex contradiction could immediately reject
this particular family.

\section{M8: Detecting a signed five-variable core}
Given five literals on distinct variables, suppose every triple of them
occurs as a clause together with its simultaneous negation. In any
assignment at least three of the five literals agree. One of the two
clauses for that triple is false. The five literals therefore certify
UNSAT, and a reviewer can verify the certificate by checking twenty
input clauses (after dropping repeated literals).

The revised hybrid indexes complementary clause triples by their first
two signed literals in increasing variable-ID order. Up to simultaneous
negation the smallest variable has positive sign. The last three
literals of every witness therefore occur in a common index bucket.
Enumerating triples of bucket entries and checking all ten supports
finds every witness of this form. This argument is invariant under
permutation and complementation of variables. With $m$ input clauses
the total number of bucket entries is at most $m$, so the number of
candidates is $O(m^3)$. Verification per candidate uses a fixed number
of membership checks over input-sized data, giving polynomial total
bit cost even with linear scans per lookup. An unsuccessful search
continues to the existing complete fallback.

\paragraph{A surviving lower bound.}
In the M7 construction replace the triples on the first five cycle
vertices by both signs of each of the three pairs on the first three
cycle vertices. The three binary constraints require three Boolean
values to be pairwise unequal, an impossibility. The new core adds
at most four occurrences per cycle vertex. Its binary clauses survive
every prefix of pivot assignments and produce no units there.

No five-variable certificate is present at the root. Two pivots share
no triple. A witness with at most one pivot would contain four cycle
vertices with all four triples present. Fix one of these four vertices.
The pairs completing it to a consecutive cycle triple form a path of
three edges among its two predecessors and two successors. To cover
the three remaining vertices pairwise this path would need a triangle.
The cycle length is at least eight, so its four neighbors are distinct.
Hence the five-variable detector misses this core under every signing.
The affine recognizer also declines because a cycle triple has just two
sign patterns. The hybrid falls back at the root. The separator,
frequency and distinct-cache-key arguments of M7 still hold: the cycle
and private blocks are unchanged, and binary clauses of the new core
have both signs regardless of the prefix. For each private block there
is a pair outside the three core vertices whose binary sign still
recovers its pivot value. Thus at least $2^{k+1}-1$ calls persist for
this revised solver. The construction has $9k$ variables and $O(k)$
clauses.

\section{M9: Binary parity inside mixed formulas}
After whole-formula affine recognition declines, collect each pair of
binary clauses $(a\lor b)$ and $(\neg a\lor\neg b)$ on distinct
underlying variables. Their conjunction says precisely that the
\emph{signed} literals have opposite truth values. A graph edge
therefore records equality or inequality of the underlying variables,
depending on their signs. Traversal labels every reached variable by
one component representative and one sign. Two paths giving opposite
signs for one variable imply an inconsistent cycle, which certifies
UNSAT independently of every other clause.

If labels agree, every assignment satisfying these edges is determined
on each component by its representative bit. Conversely each choice of
the representative bits satisfies every extracted edge. Substituting
the signed representatives into all clauses therefore preserves
satisfiability in both directions. Duplicate literals can be dropped
and tautologies discarded. A model of the reduced clauses lifts by
the same signs; the implementation verifies it against the original
formula. Components and edges require linear traversal after indexing.
Normalization, sorting and substitution all take polynomial time in
the encoded input length. A consistent parity graph alone does not
decide the remaining clauses. The M8 odd-cycle family is now rejected
during graph traversal for every $k$, including under signed renamings.

\paragraph{Equivalent ternary encoding.}
Replace every one of the six binary clauses $C$ of the M8 triangle
by $(C\lor z)\land(C\lor\neg z)$ using a single fresh variable $z$.
For either value of $z$ this equals $C$. The resulting formula has
no binary clauses at the root. M8's five-variable detector still
misses: any certificate containing $z$ would require it to share
triples with four distinct neighbors, but it has only three.
All triples omitting $z$ are among those already considered in M8.
A cycle triple outside the guarded pairs has only two clause patterns,
so whole-formula affine recognition declines.

The added vertex retains a neighbor after removal of at most two
vertices. The M7 connectivity argument persists. The guard occurs
twelve times and each triangle vertex gains at most eight occurrences
from the guarded pairs, so no auxiliary reaches the 56 occurrences
of an unassigned pivot. Prefixes still produce distinguishable binary
signs on their private pairs. No unit appears and the unsatisfiable
triangle is logically present on every branch. With parity preprocessing
only at the root, the M7 prefix-tree argument again gives at least
$2^{k+1}-1$ recursive calls. Encoded length remains $O(k\log(k+1))$.

\section{M10: A Riemann-hypothesis bridge through algebraic feasibility}
For a CNF formula $F$, introduce a polynomial variable $x_i$
for each Boolean variable and impose $x_i(x_i-1)=0$.
The falsity factor for a positive literal $x_i$ is $1-x_i$;
for a negative literal it is $x_i$. Each clause requires the product
of its falsity factors to vanish. Long products are split into
quadratic equations using prefix-product auxiliary variables, with
a Booleanity equation for each auxiliary. The construction has
$O(n+m+L)$ equations and variables in terms of the explicitly
represented variable count $n$, clause count $m$ and literal
occurrences $L$, and at most five monomials per equation.

\begin{theorem}
For every field $K$, the resulting quadratic system has a common
zero over $K$ if and only if the CNF formula $F$ is satisfiable.
\end{theorem}
\begin{proof}
The equation $x(x-1)=0$ forces $x\in\{0,1\}$ over a field.
Every auxiliary prefix variable is then uniquely forced to equal
its product of falsity factors. The final zero-product equation
requires at least one literal of every clause to be true. An
empty clause contributes $1=0$. Conversely, a Boolean satisfying
assignment extends to the auxiliary prefix products and makes all
the equations zero. Thus the implication holds in both directions.
\end{proof}

In particular, complex and prime-field feasibility are equivalent
for these specific Boolean encodings \emph{without} the Riemann
Hypothesis or the Generalized Riemann Hypothesis (GRH). This is
a reduction, not a deterministic polynomial-time SAT algorithm.
For general integer-polynomial systems, Koiran proved under GRH
that complex feasibility belongs to $\mathsf{RP}^{\mathsf{NP}}$
and hence the polynomial hierarchy~\cite{koiran}. That
conditional upper bound is not $\mathsf{P}$ and does not settle
$\mathsf{P}$ versus $\mathsf{NP}$. The formal construction,
complexity caveat for compressed input, and finite experimental
protocol are recorded in
\texttt{RIEMANN\_HYPOTHESIS\_RESEARCH\_2026\_11\_23.md}.

\section{M11: Exact SAT zeta identity and its algorithmic barrier}
Let $F$ be an explicit CNF formula with $n$ Boolean variables
and $S(F)$ satisfying assignments. Let $X_F$ be the zero locus,
over $\mathbb Z$, of the M10 quadratic equations including
auxiliary prefix products.

\begin{theorem}
For every prime $p$ and integer $r\ge1$, the point count of the
resulting scheme satisfies
\[
\#X_F(\mathbb F_{p^r})=S(F).
\]
Consequently the local Hasse--Weil point-counting series is
\[
Z(X_F/\mathbb F_p,t)
=\exp\left(\sum_{r\ge1}\frac{\#X_F(\mathbb F_{p^r})}{r}t^r\right)
=(1-t)^{-S(F)}
\]
and the arithmetic Euler product, for $\Re(s)>1$, is
\[
\zeta_{X_F}(s)=\prod_p(1-p^{-s})^{-S(F)}
=\zeta(s)^{S(F)}.
\]
\end{theorem}
\begin{proof}
Over any field, $x_i(x_i-1)=0$ forces $x_i\in\{0,1\}$.
Every prefix-product auxiliary variable is uniquely determined
by the original variables. The final zero-product equation for a
clause holds exactly when that Boolean clause is satisfied.
Thus restriction to the original variables is a bijection between
points over every $\mathbb F_{p^r}$ and satisfying assignments.
The series follows from
$-\log(1-t)=\sum_{r\ge1} t^r/r$; multiplying the prime-local
factors gives the global formula.
\end{proof}

One can also identify $X_F$ with the disjoint union of $S(F)$
copies of $\operatorname{Spec}\mathbb Z$ using
$\mathbb Z[x]/(x(x-1))\cong\mathbb Z\times\mathbb Z$.
In particular, $\zeta_{X_F}$ is identically $1$ for UNSAT
formulas and has a pole of order $S(F)$ at $s=1$ for SAT
formulas. Its first local power-series coefficient is $S(F)$,
the \#SAT counting problem. Hence deriving this coefficient or
pole order in polynomial time from arbitrary input would itself
solve \#SAT; deciding only whether the pole exists would solve
SAT. This encoding therefore reformulates rather than resolves
$\mathsf P$ versus $\mathsf{NP}$. Assuming the Riemann Hypothesis
changes no part of this computation: for $S(F)>0$ the nontrivial
zero locations are those of ordinary $\zeta(s)$, with
multiplicities scaled by $S(F)$.

The identity uses standard arithmetic-zeta definitions
\cite{musta} and requires neither RH nor GRH. By contrast,
Koiran's general algebraic-feasibility upper bound cited in M10
is conditional on GRH. The bounded Python program
\texttt{zeta\_sat.py} performs explicit exponential model
enumeration and computes the exact local coefficients from a
supplied model count; it is not a general polynomial-time solver.
See \texttt{SAT\_ZETA\_RIEMANN\_RESEARCH\_2026\_11\_23.md}
for the full proof, independent field-extension tests and limits.
